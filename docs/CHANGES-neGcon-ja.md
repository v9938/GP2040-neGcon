# neGcon の変更内容

ソースのリリース識別子は `0.7.12-neGcon`、数値のCMakeプロジェクトバージョンは `0.7.12` です。成果物の日付とビルドIDはリリーススクリプトで指定し、文書に固定した時刻は使用しません。

## 現在のソースの動作

- neGcon Iの初期値はモード `12`（RY負方向）、IIはモード `11`（RY正方向）、Lはモード `0`（アナログ割当なし）です。
- I・II・Lにはそれぞれ独立したデジタル有効設定、内側デッドゾーン、外側の最大到達点があります。デジタル有効設定は `0` / `1` で初期値はON、内側の初期値は `0%`、外側の初期値は `100%` です。有効な値には `inner < outer` が必要です。デジタル押下の判定は生の感圧値と閾値を使い、アナログ割当とは独立しています。
- これら9項目はファームウェア設定、Web編集、TXTプリセット、ネイティブPC編集、共有アナログプレビューモデルで扱います。
- 感圧出力はtwistの軸や他の感圧出力と重複して割り当てられます。各寄与を合計してから、最後に出力範囲へ制限します。fullの加算量は `(u - 0.5) * 65535` です。`u` は最大到達点とデッドゾーンの変換後に正規化した感圧値で、`u=0` では負の半スケール `-32767.5`、最大の `u=1` では正の半スケール `+32767.5` を既存軸へ加算します。軸全体の最小値から最大値へ絶対値を変換して上書きする処理ではありません。方向指定とトリガーには、それぞれ対応する符号付き・単極性の寄与を使用します。
- TXT出力はプリセット形式バージョン `3` です。対応する旧バージョンの入力は現在のパーサーで正規化します。サンプル・仕様書・パーサーテストは保持してください。共有プレビューABIはバージョン `3` のまま、感圧の最大到達点を扱うフィールドが更新されています。対応する再ビルド済みDLLとPythonインターフェースを組み合わせてください。
- 設定フッターの識別値は `0x50535833` です。互換性のない旧識別値の設定は拒否し、初期値に置き換えます。書き込む前に必要なプロファイルをバックアップしてください。以前の保存設定がすべて残ると想定しないでください。

## Releaseビルド

ソースのルートで使用する移植可能なビルドラッパーは、外部のPico SDK `2.1.1` とArm GNU Toolchain `14_2_Rel1` に対応します。初期状態では個人のパスを埋め込まず、不足ライブラリーの取得、Web UIの再生成、実機への書き込み、別の配布先へのコピーを行いません。PythonパッケージのインストールとnpmによるWeb再生成には、明示的なオプション指定が必要です。[日本語ビルド手順](BUILD-neGcon-ja.md)を参照してください。

## 検証の範囲

PCパーサー、共有計算、API契約、Webシミュレーションのテストは実機を使いません。これらの成功だけを根拠に、最新のneGconソースの変更を実機へ書き込み済み・実機検証済みと説明してはいけません。過去の `0x3bc` / `0x6b` の実機ログは以前のファームウェア実行の記録であり、このリリースを検証するものではありません。この文書は新しい実機試験や新しいファームウェアビルドの実施を示すものではありません。
