# PC版オフラインTXTプロファイルエディター

Windows x64向けのネイティブWin32/MSVCアプリです。TXTファイルを編集するだけで、WebView2、ブラウザー、ネットワーク、Python、シリアルポート、ファームウェアのビルド、機器への書き込みは使用しません。実装は `../pc-profile-editor/` にあり、独立した `usb-host-tester` はこのアプリの対象ではありません。

## 配布ファイル

配布時の実行ファイルの配置は次のとおりです。文書にパスがあることだけで、バイナリーの配置や動作確認が完了したことを示すものではありません。

- `../pc-profile-editor/bin/psx_profile_editor.exe`
- `../pc-profile-editor/bin/analog_preview.dll`

エディターはTXT編集にDLLを必要としません。`analog_preview.dll` は別のPCアナログシミュレーション用で、実際のUSB出力や機器接続を行うものではありません。シミュレーションには、感圧の最大到達点フィールドが一致したABIバージョン3のDLLとPythonインターフェースを使用してください。TXTバージョンとDLLのABIバージョンは独立した仕様です。MSVCランタイムは静的リンクです。署名のない実行ファイルにはWindows SmartScreenの警告が出る場合があります。アプリやビルドスクリプトはセキュリティーポリシーを変更しません。

## ソースからのビルド

Visual Studio 2022 Communityの「C++によるデスクトップ開発」、Windows SDK、CMakeを用意してください。ソースのルートから実行します。

```powershell
pwsh -File pc-profile-editor/build.ps1
```

スクリプトは `Visual Studio 17 2022`、x64、Release、並列数1を選びます。コンパイラーの実行ファイルを推測したり、パッケージをダウンロードしたりしません。ビルド出力と配布用の `bin` は別の場所です。

- `../pc-profile-editor/build/Release/psx_profile_editor.exe`
- `../pc-profile-editor/build/Release/preset_tests.exe`
- `../pc-profile-editor/build/Release/analog_preview.dll`

DLLは移植可能な `../headers/analog_preview.h`、`../src/analog_preview.cpp` と、存在する場合は `../src/jogcon.cpp` を `ANALOG_PREVIEW_DLL` を指定してコンパイルします。

## 編集操作

日本語UIには2つのタブがあります。最初のタブではPSXの16入力に対し、予約名を除く131種類の正式な `GpioAction` 名から割り当てを選びます。2つ目のタブにはセクション・カテゴリーツリー、検索できる複数列のプロパティー一覧、選択した項目の型に対応した編集欄があります。文字列・数値は入力欄、bool・列挙値は選択欄で編集します。行をダブルクリックすると対応する編集欄へ移動します。文字列にはTXTの引用符を入力せず、値の適用ボタンで変更を下書きへ反映してください。

新規作成は有効なニュートラル設定例を作ります。ファームウェアの初期設定をそのまま取り出したものではありません。開く操作は `.gp2040-psx.txt` / `.txt` を全項目の検証後に読み込みます。名前を付けて保存する操作も、文書全体を検証してから書き込みます。自動保存はありません。未保存の変更がある場合は、終了・新規作成・開く操作の前に確認します。

`Profile.source` は出力元の記録だけです。編集しても実機のプロファイルは選択されません。`Profile.label` は共通仕様によりASCII英字・数字・スペースだけ、最大16バイトです。マクロのラベルとWindowsのファイルパスには日本語を使用できます。

共有ADDON設定、キーボードHID割当、3つのReactive LEDチャンネル、6つのマクロと各入力の `buttonMask`・`duration`・`waitDuration` を含む、対応するすべての項目を編集できます。時間の単位はマイクロ秒です。マクロの `inputCount` を `0..30` に設定すると入力行を作成します。減らす場合は末尾の行を削除する前に確認します。編集途中では項目間の矛盾が一時的に残る場合がありますが、全体の検証と保存は矛盾を拒否します。`CUSTOM_BUTTON_COMBO` 以外のアクションを選ぶとカスタムマスクを消去し、意図せず有効なまま残ることを防ぎます。

共有ADDON設定は全プロファイルに影響します。GPIO・認証・USB識別情報は許可リストに含まれず、無視するのではなく拒否します。機器全体のバックアップ形式ではありません。保存したTXTを機器へ反映する操作は、別のWeb設定画面で明示的に行ってください。

## TXT v3と旧ファイル

新規作成と保存はTXTバージョン3です。[共通プリセット仕様](../preset-format/SPECIFICATION.md)を参照してください。ネイティブパーサーの現在のスキーマと移行処理は `../pc-profile-editor/src/preset.cpp` にあります。実装元READMEの旧v2説明ではなく、現在の仕様と実装に従います。

| 入力バージョン | 必要なスキーマ | 読込時に補う項目 |
|---|---|---|
| v1 | JOGCONの3項目とneGconの新規9項目を含まない旧スキーマとの完全一致 | JOGCONの `0 / 100 / 1` とneGconの9項目の初期値 |
| v2 | JOGCONの3項目が必須で、neGconの新規9項目を含まない旧スキーマとの完全一致 | neGconの9項目の初期値だけ |
| v3 | 現在の全必須項目 | 欠落を補完せず拒否 |

旧バージョンに新しいキーがある場合も未知キーとして拒否します。v1/v2/v3以外のバージョンは拒否します。移行では既存のマッピング・マクロ・設定を保持し、再出力はv3になります。既存のneGconモード `14=RT` / `13=LT` を、新規初期値の `12=RY center-` / `11=RY center+` に置き換えません。ただし旧ファイルも現在の加算方式で動作するため、旧fullの軸全範囲への上書き動作は維持されません。

汎用プロパティー一覧で、次のJOGCON設定とneGcon設定を数値として編集できます。`0/1` の設定もTXT・ネイティブではboolではなく整数です。

| 項目 | 範囲と初期値 |
|---|---|
| `jogconDeadzone` | 整数 `0..32766`、`jogconMax` 未満、初期値 `0` |
| `jogconMax` | 整数 `1..32767`、初期値 `100` |
| `jogconForcebackEnabled` | 整数 `0/1`、初期値 `1` |
| `negconIDigitalEnabled` / `negconIIDigitalEnabled` / `negconLDigitalEnabled` | 整数 `0/1`、初期値 `1` |
| `negconIInnerDeadzone` / `negconIIInnerDeadzone` / `negconLInnerDeadzone` | 整数 `0..100`（%）、初期値 `0` |
| `negconIOuterDeadzone` / `negconIIOuterDeadzone` / `negconLOuterDeadzone` | 整数 `0..100`（%）、初期値 `100`、同じ入力のinnerより大きい |

PC模擬モーターの一時状態はTXTに保存しません。感圧とtwist、感圧同士の重複割当は許可され、各寄与の合計後にだけ出力範囲へ制限します。fullの加算量 `(u - 0.5) * 65535` は補正済みの感圧 `u=0` で `-32767.5`、`u=1` で `+32767.5` です。未押下でも既存軸を負方向へ動かします。DSの2ペアには引き続き異なるLS/RS出力が必要です。

## ファイルの検証と保存

- UTF-8で、先頭BOMは任意です。最大サイズはBOMを含む65536バイトです。改行はLFまたはCRLFで、単独CRは拒否します。
- `#` で始まる行全体のコメントを許可します。行末コメントは許可しません。セクション・キーは大文字小文字を区別し、重複・未知・欠落・不正なデータを拒否します。
- 引用文字列はJSON形式のエスケープと有効なサロゲートペアを扱います。復号後の制御文字と不正なサロゲートは拒否します。
- 通常の十進数と非負の `0x` 16進数を扱い、指数表記は許可しません。小数は許可された項目だけに使用でき、有限値・範囲・整数であることを検証します。
- 正式なアクション名、予約名の拒否、マスクの制約、出力の矛盾を検証します。

保存はBOMなしの読みやすいUTF-8、十進数、標準の説明コメントで出力します。入力のコメント位置や項目順は保持しません。同じディレクトリーの `.tmp` に書き込み、`FlushFileBuffers`、置換・write-through指定の `MoveFileExW` の順に処理します。既存の `.tmp` は上書きしません。書き込みに失敗した場合は元のファイルを保持し、エラーを表示します。

## テストと検証の範囲

`preset_tests.exe` は実機を使わない移植可能なパーサー・スキーマテストです。CTestにはWindowsのアトミック保存テスト、日本語パス、既存一時ファイルの保護、実際のWin32コントロールによるGUIスモークテストがあります。共通サンプルと旧v1サンプルの互換性も移植可能なCTestで確認します。

```text
preset_tests.exe --roundtrip <TXT-path>
preset_tests.exe --emit-default
psx_profile_editor.exe --smoke-ui
```

`--roundtrip` は書き込みを行わずサンプルを確認し、`--emit-default` は有効な新規文書を標準出力へ表示します。`--smoke-ui` は実際のWin32コントロールを作成し、アクション選択欄・動的なマクロ行・往復変換の検証を確認して、終了ステータスを返します。手作業の見た目の確認に代わるものではありません。これらのテストやPCシミュレーションは、実機の動作、実際のUSBタイミング、最新ファームウェアの書き込み成功を確認するものではありません。
